⚙ Panel Admin & Integrasi Google Spreadsheet

Hubungkan aplikasi yang berjalan di GitHub Pages langsung ke Google Spreadsheet via Apps Script Web App.

Status: Terhubung Cloud Google Sheets

1. Tautan Web App Google Apps Script (Exec URL)

Tautan ini didapat setelah melakukan deploy skrip sebagai Web App di Google Sheets Anda.

*Tautan resmi sekolah telah tertanam permanen sebagai default bawaan. Semua operasi penambahan, perubahan, dan analisis RKAS disinkronkan langsung ke Spreadsheet.

📥 TARIK DATA (Spreadsheet → Aplikasi)

Mengambil pagu anggaran, data master, dan rincian RKAS terkini dari Google Sheets ke dalam aplikasi.

📤 KIRIM DATA (Aplikasi → Spreadsheet)

Mengunggah seluruh data saat ini (anggaran, kegiatan, barang, dan rincian RKAS) untuk disimpan permanen ke Google Sheets.

2. Kode Script Google Apps Script (`Code.gs`)

Mendukung otomatisasi 12 Sheet Bulanan (JANUARI – DESEMBER) + Sheet Master.

Langkah Pembaruan Skrip Spreadsheet:

  1. Buka Google Spreadsheet Anda, klik menu Extensions (Ekstensi) > Apps Script.
  2. Hapus kode lama di berkas Code.gs, lalu klik tombol Salin Seluruh Kode Script di atas dan Paste ke sana.
  3. Klik ikon Save (Simpan) lalu klik Deploy > Manage deployments > klik Edit (ikon pensil) > pilih New version > Deploy.
  4. Setiap input, edit, dan hapus baris RKAS di aplikasi otomatis tersinkron ke sheet bulan masing-masing!
